# AegisLocal Update Service

This public repository hosts Windows update releases and update metadata for AegisLocal.

The AegisLocal desktop app checks this repository for releases. When a new version is available, the app shows the installed and available versions, asks for approval, and then downloads, installs, and restarts in-app.

- Publisher: B.Navin Kumar
- Update channel: stable GitHub Releases
- Supported installer: Windows x64 NSIS

Release assets are application binaries and updater metadata. This repository is the update distribution endpoint; it does not contain the application source code.
